## 오퍼레이션 6개 (WADL 발견 결과)

포털 상세페이지의 한글 설명 ↔ 실제 오퍼레이션명 매핑:

| 포털 설명 | 오퍼레이션 | 파라미터 |
|---|---|---|
| 기술사 시험 시행일정 | `getPEList` (Professional Engineer) | ServiceKey |
| 기능장 시험 시행일정 | `getMCList` (Master Craftsman) | ServiceKey |
| 기사·산업기사 시험 시행일정 | `getEList` (Engineer) | ServiceKey |
| 기능사 시험 시행일정 | `getCList` (Craftsman) | ServiceKey |
| 종목별 응시수수료 | `getFeeList` | ServiceKey + `jmCd` |
| 종목별 시행일정 목록 | `getJMList` | ServiceKey + `jmCd` |

> 등급별(PE/MC/E/C) 오퍼레이션은 **등급 전체 공통 일정**을, `getJMList`는 **종목 단위 일정**을 준다.
> 포털 설명: "종목별 시험일정이 등급 시험일정과 상이할 수 있으므로 종목 일정은 getJMList 사용 권장".

**WADL 발견 방법** (다른 q-net 서비스에도 동일 적용 가능):
```
http://openapi.q-net.or.kr/api/service/rest/InquiryTestInformationNTQSVC?_wadl&_type=xml
→ <resource path="getJMList"> ... 로 오퍼레이션·파라미터 목록 노출
```

## getJMList — 종목별 시행일정 (핵심, jmCd 필수)

> ⚠️ **현재 연도 데이터만 반환**(활용가이드 명시). 과거/미래 연도가 필요하면 1번(implYy 지정)을 함께 써야 함.

**호출 예:**
```
http://openapi.q-net.or.kr/api/service/rest/InquiryTestInformationNTQSVC/getJMList?ServiceKey={SERVICE_KEY}&jmCd=1320
```

**응답 필드** (item = 종목의 회차 1건). ※ XML 태그가 **전부 소문자**:

| 필드 | 설명 |
|---|---|
| `jmfldnm` | 종목명 (예: 정보처리기사) |
| `implplannm` | 시행계획명 (예: `2026년 정기 기사 1회`) |
| `docregstartdt` / `docregenddt` | 필기 원서접수 시작/종료 |
| `docexamstartdt` / `docexamenddt` | 필기시험 시작/종료 |
| `docpassdt` | 필기 합격발표 |
| `docsubmitstartdt` / `docsubmitenddt` | **서류제출 기간** (1번엔 없는 필드) |
| `pracregstartdt` / `pracregenddt` | 실기 원서접수 시작/종료 |
| `pracexamstartdt` / `pracexamenddt` | 실기시험 시작/종료 |
| `pracpassstartdt` / `pracpassenddt` | **실기 합격발표 기간**(시작~종료) |
| `obligfldcd/nm`, `mdobligfldcd/nm` | 대/중 직무분야 |

**실측(정보처리기사 jmCd=1320, 2026):** `2026년 정기 기사 1회` 기준
필기접수 01-12~01-15 · 필기 01-30~03-03 · 필기발표 03-11 · 서류제출 01-30~03-20 · 실기접수 03-23~03-26 · 실기 04-18~05-06 · 실기발표 06-12~08-11.
→ 원본: `samples/종목별시험정보_getJMList_정보처리기사.xml`

## getFeeList — 종목별 응시수수료 (jmCd 필수)

**응답:** `contents`("1차 : 19400, 2차 : 22600"), `infogb`("응시수수료"), `jmfldnm`, 직무분야.
**실측(정보처리기사):** 필기 19,400원 / 실기 22,600원. → cert 상세 페이지 강화용.
원본: `samples/종목별시험정보_getFeeList_정보처리기사.xml`

## getEList — 기사/산업기사 등급 공통 일정 (파라미터 없음)

**응답 필드:** `description`("기사,산업기사(2026년도 제1회)"), `docregstartdt/enddt`, `docexamdt`(필기 단일일), `docsubmitstartdt/entdt`, `docpassdt`, `pracregstartdt/enddt`, `pracexamstartdt/enddt`, `pracpassdt`.
※ getJMList와 달리 `docexamdt`가 **단일 날짜**, 태그명도 일부 다름(`docsubmitentdt` 오타성 표기 주의).
**실측:** 기사·산업기사 제1회가 접수기간만 다른 2행(정기/추가) — 1번과 동일한 중복 패턴.
원본: `samples/종목별시험정보_getEList_기사산업기사.xml`

## 등급별(get*List) vs 종목별(getJMList) 스키마 차이 (활용가이드 확정)

| 구분 | 등급별 (getPEList/MCList/EList/CList) | 종목별 (getJMList) |
|---|---|---|
| 회차 필드 | `description` | `implplannm` |
| 종목명 | 없음 | `jmfldnm` 있음 |
| 필기시험일 | `docexamdt` (단일) | `docexamstartdt`/`docexamenddt` (구간) |
| 서류제출 종료 | **`docsubmitentdt`** (ent) | **`docsubmitenddt`** (enddt) ← 철자 다름! |
| 합격자발표 | `pracpassdt` (단일) | `pracpassstartdt`/`pracpassenddt` (구간) |
| 직무분야 코드 | 없음 | obligfld/mdobligfld 4필드 포함 |
| prac* 의미 | 기술사(PE)=**면접**, 나머지=**실기** | 실기 |

## 구현 메모

- 태그명이 **소문자**이고 1번(카멜케이스)과 다르다 → 어댑터에서 필드 매핑 분리.
- **서류제출 종료 태그 철자가 오퍼레이션마다 다름**(등급별 `docsubmitentdt` / 종목별 `docsubmitenddt`) — 오타 같지만 실제 필드명이니 각각 매핑. 정규화 계층에서 흡수.
- **필드가 통째로 누락된 회차**가 있다(서류제출·실기 등) → 전 날짜 필드 nullable 처리.
- 날짜·코드는 전부 문자열. 응시수수료(`contents`)는 `"1차 : 19400, 2차 : 22600"` 자연어라 파싱 필요.
- 국가기술자격 수집 파이프라인: **getJMList(jmCd 순회)** 로 종목별 일정 + **getFeeList**로 수수료 → certificate/exam_schedule 채움. 단 getJMList는 현재연도만이므로 과거 회차는 1번 병행. jmCd 목록은 2번에서 확보.
