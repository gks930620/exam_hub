# 0. 결론 — 시험 응시자 관점에서 어떤 Q-net API를 쓸까

> 큐넷 API를 7개 신청해 조사했고, **2개는 중지**(불필요/실패)해서 **지금은 5개를 쓴다**.
> 이름이 비슷해 헷갈리니, 이 문서 하나로 **"결국 이렇게만 요청하면 된다"** 를 정리한다.
> 판단 기준: **"내가 이 시험을 보려는 사람이라면 당연히 알아야 할 것"**. 상세 스펙은 각 번호 문서 참고.

---

## A. 시험 보려는 사람이 당연히 알아야 할 것

| 알아야 할 것 | 구체적으로 | 우선순위 |
|---|---|:--:|
| **언제 접수·시험·발표하나** | 원서접수 시작/마감, 시험일, 합격발표일 | 🔴 필수(앱의 존재이유) |
| **얼마인가** | 응시수수료(필기/실기) | 🔴 필수 |
| **뭘 평가하나** | 시험과목, 검정방법(필기/실기/면접) | 🔴 필수 |
| **어떻게 붙나** | 합격기준(예: 60점 이상) | 🔴 필수 |
| **어떻게 준비하나** | 출제경향, 출제기준 | 🟡 중요 |
| **얼마나 어렵나** | 합격률, 응시자수(경쟁률) | 🟢 있으면 좋음 |
| **누가 시행하나** | 시행처(한국산업인력공단) | 🟢 부가 |

---

## B. 정보 니즈 → 어느 API가 주나

| 알아야 할 것 | 담당 API | 파라미터 |
|---|---|---|
| 시험일정(접수·시험·발표) | **1번** getQualExamSchdList | `jmCd`, `implYy`, `qualgbCd` |
| 응시수수료 | **3번** InquiryTestInformationNTQSVC `/getFeeList` | `jmCd` |
| 시험과목·검정방법·합격기준·출제경향 | **5번** InquiryInformationTradeNTQSVC `/getList` | `jmCd` |
| 자격증 이름·계열·직무분야(목록) | **2번** InquiryListNationalQualifcationSVC `/getList` | (없음) |
| 합격률·응시자수(경쟁률) | **4번** InquiryStatSVC | `baseYY`, `jmCd` |
| 서류제출 기간(보조) | 3번 `/getJMList` | `jmCd` |

> 핵심: **거의 모든 정보가 `jmCd`(종목코드) 하나로 조회된다.** 그래서 `jmCd`가 이 앱의 중심 키다.

## C. 5개 API 판정 — 필수 / 선택

### 🔴 필수 4개 (이것만 있으면 앱이 성립)

| # | API | 주는 것 | 이유 |
|:-:|---|---|---|
| **2** | 종목 목록 | 자격증 613종의 이름·계열·직무분야 | 무슨 자격증이 있는지 목록·검색·시드의 근간 |
| **1** | 시험일정 | 전 자격구분 접수·시험·발표일 | 앱의 존재이유(알림·D-day). **전문자격까지 커버(검증완료)** |
| **3** (`getFeeList`) | 응시수수료 | 필기/실기 가격 | "얼마냐"는 필수 정보, 유일한 소스 |
| **5** | 종목별 자격정보 | 시험과목·검정방법·합격기준·출제경향 | "뭘 평가하고 어떻게 붙나" — 준비의 핵심 |

### 🟡 선택 2개 (있으면 더 좋음)

| # | API | 주는 것 | 판단 |
|:-:|---|---|---|
| **4** | 통계 | 합격률·응시자수 | "얼마나 어렵나" 경쟁률 뱃지에 좋음. 연 1회 갱신이라 붙이기 쉬움. **후순위** |
| **3** (`getJMList`) | 종목별 일정(서류제출 포함) | 종목명+서류제출기간+수수료를 한 번에 | 1번과 겹침. **서류제출 기간이 꼭 필요할 때만** 보조 |

### ⛔ 중지한 2개 (신청했다가 뺌 — 참고)

| 옛 번호 | API | 왜 뺐나 |
|:-:|---|---|
| (옛 5) | 국가전문자격 시험 시행일정 (`InquiryTestDates…`) | **1번과 중복.** 세무사(jmCd=9641)를 1번으로 조회하니 동일한 63회 1·2차 일정이 나옴(검증완료). 1번이 `qualgbCd=S`로 전문자격을 이미 커버 → 중지 |
| (옛 6) | 국가기술자격 종목 정보 (`InquiryQualInfo`) | 응답이 1000KB 상한 초과로 **상시 실패**(페이징·필터 다 무효). 개요·진로전망은 없어도 앱 성립 → 중지. 핵심(시험과목 등)은 5번이 대체 |

## D. 왜 헷갈렸나 (이름 비슷한 것들 교통정리)

- **"일정" 주는 API가 3개였다** (1 · 3 getJMList · 옛5 전문자격) → **1번으로 통일.** 3번 getJMList는 서류제출 보조, 옛5는 중지.
- **"자격정보" 주는 API가 2개였다** (옛6 InquiryQualInfo · 5번 InquiryInformationTrade) → **5번으로 통일.** 옛6은 실패.
- **수수료는 독립 API가 아니라 3번 안의 한 오퍼레이션**(`getFeeList`)에 숨어 있음.
- **`jmCd`(종목) vs `seriesCd`(계열) vs `baseYY`(연도)** — 파라미터로 성격이 갈린다. 우린 **jmCd 기반만** 쓰면 된다(2·1·3fee·5). seriesCd 기반(중지한 옛5·옛6)은 안 씀.

## E. 결론 — 실질적으로 이렇게 요청하면 된다

### 자격증 1개(예: 정보처리기사 `jmCd=1320`) 상세를 채우는 호출

```
1) [앱 최초 1회, 배치] 종목 마스터 전체 — 2번
   GET http://openapi.q-net.or.kr/api/service/rest/InquiryListNationalQualifcationSVC/getList
   → 613종의 jmCd·이름·계열 확보 (검색/목록/시드)

2) [종목별] 시험일정 — 1번
   GET https://apis.data.go.kr/B490007/qualExamSchd/getQualExamSchdList
       ?dataFormat=json&implYy=2026&qualgbCd=T&jmCd=1320&numOfRows=50&pageNo=1
   → 접수·시험·발표일 (알림·D-day의 원천)

3) [종목별] 응시수수료 — 3번 getFeeList
   GET http://openapi.q-net.or.kr/api/service/rest/InquiryTestInformationNTQSVC/getFeeList?jmCd=1320
   → "1차 : 19400, 2차 : 22600"

4) [종목별] 시험과목·검정방법·합격기준·출제경향 — 5번
   GET http://openapi.q-net.or.kr/api/service/rest/InquiryInformationTradeNTQSVC/getList?jmCd=1320
   → infogb: 출제경향 / 출제기준 / 취득방법(①시행처 ②관련학과 ③시험과목 ④검정방법 ⑤합격기준)

5) [선택] 합격률·응시자수 — 4번
   GET http://openapi.q-net.or.kr/api/service/rest/InquiryStatSVC/getEventYearPiList?baseYY=2024&jmCd=1320
   → 2024 접수 96,287 / 응시 66,169 / 합격 40,207 (합격률 ≈61%)
```

> 모든 호출에 인증키(`ServiceKey`)와 [README §0](README.md)의 HTTP/키 인코딩 규칙 적용.
> `qualgbCd`는 종목이 기술(T)/전문(S)/과정(C)/일학습(W) 중 무엇인지에 따라. 2번 마스터의 `qualgbcd`로 안다.

### 정보처리기사 상세 = 위 호출로 만들어진 실제 화면

| 화면 섹션 | 값 (실호출) | 출처 |
|---|---|---|
| 제목/계열 | 정보처리기사 · 기사 · 정보통신>정보기술 | 2번 |
| D-day/일정 | 2026 제3회 접수 07-20~07-23(+추가 08-01~02), 필기 08-07~, 실기 10-24~ | 1번 |
| 응시료 | 필기 19,400원 / 실기 22,600원 | 3번 getFeeList |
| 시험과목·검정·합격기준 | (①~⑤ 원문) | 5번 |
| 경쟁률 | 2024 필기 합격률 약 61% | 4번(선택) |

---

## F. 한 줄 결론

> **`jmCd` 기준으로 [2번 마스터] + [1번 일정] + [3번 getFeeList 수수료] + [5번 자격정보] 네 개면 된다.**
> 합격률(4번)은 여유되면 추가. 신청했던 7개 중 2개(옛 5·6번)는 중지 — 국가전문자격 일정은 1번이 커버하고, 종목 서술정보 API는 대용량으로 실패했다.
