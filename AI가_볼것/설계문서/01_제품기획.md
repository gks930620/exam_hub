## 2. 문제 정의

| 구분 | 내용 |
|---|---|
| 문제 | 국가기술자격 원서접수 기간은 **회차당 며칠**에 불과. 놓치면 다음 회차(보통 3~6개월 뒤)까지 대기 → 취업·승진·수당 일정이 통째로 밀림 |
| 현재 대안 | 큐넷 사이트 직접 조회(로그인·복잡한 UI), 카페/블로그 일정 정리글(갱신 안 됨), 개인 캘린더 수동 등록(등록 자체를 잊음) |
| 근본 원인 | 일정 정보는 공개되어 있으나 **"때가 되면 나를 찔러주는" 채널이 없음** — 조회형 정보와 행동 시점의 불일치 |
| 시장 크기 | 국가기술자격 응시 연 **200만+건** (필기+실기). 여기에 국가전문자격·공인민간자격까지 확장 여지 |

## 3. 타깃 & 페르소나

### 페르소나 A — 취준생 "김준혁" (25세, 4학년)
- 정보처리기사·SQLD 준비. 학기 중이라 접수 공지를 챙길 여력이 없음
- 지난 학기 **정보처리기사 실기 접수를 놓쳐** 졸업 후 공백기가 늘어난 경험
- 원하는 것: "내가 등록한 자격증만, 접수 열리기 전날 딱 한 번 알려줘"

### 페르소나 B — 직장인 "박서연" (33세, 시설관리팀)
- 회사 자격 수당 때문에 전기기사·소방설비기사 준비. 업무 중 큐넷 확인 불가
- 회차별 필기/실기 일정이 얽혀 있어 **"다음에 뭘 언제 접수해야 하는지"** 늘 헷갈림
- 원하는 것: 관심 자격증 여러 개의 연간 일정을 한 화면에서 + 마감 임박 경고

## 4. 핵심 가치 (Value Proposition)

| 순위 | 가치 | 설명 |
|---|---|---|
| 1 | **접수 알림** | 원서접수 시작 **전날 + 당일 아침** 푸시. 마감 전날 리마인드까지. 이 한 개 기능이 제품의 존재 이유 |
| 2 | D-day | 관심 자격증의 다음 시험일까지 남은 날을 홈에서 즉시 확인 → 학습 페이스 관리 |
| 3 | 연간 캘린더 | 회차별 접수기간·시험일·발표일을 한 화면에 — "올해 남은 기회가 몇 번인지" 가시화 |

## 5. MVP 기능 (5개 잠금 — 스코프 크립 금지)

1. 자격증 검색·관심 등록
2. 시험일 D-day (홈 화면)
3. **원서접수 시작/마감 푸시 알림 (FCM)**
4. 자격증별 연간 일정 캘린더
5. 자격증별 pSEO 웹 페이지 (유통용, 서버 렌더)

## 6. 경쟁 & 차별화

| 대안 | 한계 | 우리의 차별점 |
|---|---|---|
| 큐넷(Q-Net) | **조회만 가능**, 알림 없음. UI 복잡, 모바일 열람 불편 | 관심 등록 → **푸시가 먼저 찾아옴** (Pull→Push 전환) |
| 네이버 카페/블로그 정리글 | 수동 정리라 갱신 누락·오정보 | 공공 API 일 1회 자동 수집 + diff 검증 |
| 캘린더 수동 등록 | 등록 행위 자체를 잊음, 회차 변경 미반영 | 등록은 자격증 1회 탭, 이후 일정 변경도 자동 추적 |
| 종합 수험 앱(문제풀이 위주) | 일정 기능은 부가 기능이라 부정확 | **일정·알림 단일 기능**에 집중한 최경량 앱 |

> 포지셔닝: "자격증 공부 앱"이 아니라 **"자격증 일정 비서"**. 공부는 안 시킨다. 놓치지만 않게 한다.

## 8. 유통 전략

### 8-1. pSEO (웹, 서버 렌더 HTML)

- URL 구조: `/cert/{slug}` (예: `/cert/정보처리기사`) — 자격증당 1페이지 대량 생성
- 페이지 구성: `{자격증명} {연도} 시험일정` H1 + 회차별 일정 표 + D-day + 접수 임박 배지 + 앱 설치 CTA
- 타깃 검색어 패턴: `{자격증명} 시험일정`, `{자격증명} 접수`, `{자격증명} 2026 일정`
- 국가기술자격 500+ 종목 × 연도 = 수백~수천 페이지. sitemap.xml 자동 생성, 일정 갱신 시 페이지도 자동 갱신
- 연도 키워드("2026 정보처리기사 일정")는 매년 신규 트래픽 유입원

### 8-2. ASO 키워드 (10개+)

- 앱 이름 후보: "자격증 알리미 — 시험일정 D-day·접수 알림" (핵심 키워드 전방 배치)

## 11. 성공/중단 기준

- **계속**: 90일 시점 pSEO 방문 2만+ 또는 설치 3천+ 중 하나 달성 → 프로 결제 붙이고 자격증 종류 확장
- **유지**: 지표 절반 수준 → 수집 배치만 돌리며 방치(유지보수 낮음이 장점)
- **중단**: 수집 유지비 > 수익이고 성장 정체 → 웹 페이지만 남기고 앱 지원 종료
