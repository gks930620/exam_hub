# 어학 실 스크래핑까지 켜서 확인

## 6. 알아둘 함정 (안 보면 헤맴)
- **문서 위치**: 시험 데이터 관련은 전부 **`설계/시험데이터/`** 로 모았다(2026-08-10). 나머지 설계는 `설계/설계문서/`.
- **큐넷 API**: `openapi.q-net.or.kr`는 **HTTP만**(HTTPS 타임아웃). 인증키 **Encoding/Decoding** 구분(자동인코딩 클라이언트는 Decoding). 상세 `설계/시험데이터/큐넷_API/README.md` §0.
- **시드가 네 개다**: ① `seed/qnet_master.json`(**613종, jmCd 포함** — 큐넷 API 응답) ② `seed/exam_master.json`(478종, 비큐넷) — 둘 다 일정 없음, 로더 `CertificateMasterInitializer`(qnet 먼저 읽는다) ③ `seed/non_qnet_exams.json`(52종, **일정 있음**, 로더 `SeedFileScheduleSource`) ④ `seed/certificate_lifecycle.json`(폐지·개칭 24종). `exam_master.json` 은 **운영에서도 적재**되고(실참조 데이터), 일정 있는 `non_qnet_exams.json` 만 `@Profile("!prod")` 다. `provenance`가 `scraped`=실데이터(한능검·ADsP), `approx`=추정치(50종).
- **일정 없는 시험도 정상 취급**: `Certificate`(마스터)와 `ExamSchedule`(일정)이 분리 적재된다. 일정이 없으면 `hasSchedule=false` → 화면에 `일정 미정`. 예전 구조(일정 있어야 시험 존재)로 되돌리지 말 것.
- **스크래퍼는 기본 off**: `scrape.enabled=true` 일 때만 빈이 올라온다. 파싱은 `src/test/resources/fixtures/` 픽스처로 테스트하므로 **테스트가 네트워크를 안 탄다**. 사이트가 바뀌면 수집 로그에 WARN 이 뜬다.
- **SecurityConfig 화이트리스트**: React 라우트를 추가하면 `SecurityConfig` permitAll 목록에도 넣어야 한다. 빠뜨리면 그 경로에서 **새로고침 시 403**.
- **모든 시험이 같은 모델**: `Certificate`+`ExamSchedule`로 들어가서 검색·관심·D-day·알림이 자동 동작. 소스 추가 = `ScheduleSource` 구현 1개 추가.
- **포트**: 로컬 백엔드는 **8081 고정**(2026-08-06 사용자 지시). 8080 은 다른 프로젝트가 점유하는 일이 잦아 기본값에서 뺐다.
- **프런트 프록시 함정 2건(2026-08-06 수정됨)**: ① `vite.config.ts` 가 `process.env.VITE_API_TARGET` 을 읽었는데 Vite 는 `.env` 를 `process.env` 에 넣지 않는다 → 항상 기본 포트로 프록시됐다. `loadEnv` 로 교체. ② `tsc -b` 가 `vite.config.js` 를 소스 폴더에 내보냈고 **Vite 는 `.js` 를 `.ts` 보다 먼저 읽어** 설정 수정이 반영되지 않았다. `outDir` 을 `node_modules/.tmp` 로 돌림.
- **셸에서 한글 쿼리 테스트 금지**: Git Bash 가 한글을 CP949 로 보내 `?query=토익` 이 400/0건이 된다. 앱 버그가 아니다 — `fetch` 스크립트(UTF-8 파일)로 확인할 것.
- **DTO record 잔존**(CertificateDtos 등) — code-convention은 class 규칙. 후속 정리 대상(01_AI_작업큐 §4).
