# 매니저 매뉴얼 — 시험 일정 직접 넣기

> 이 문서는 **운영자(매니저)** 를 위한 것입니다. 개발자가 아니어도 따라 할 수 있게 썼습니다.
> 작성 2026-08-07 · **갱신 2026-08-10**(매니저 로그인 분리 + 화면 안의 데이터 지도).

---

## 1. 내가 하는 일이 뭔가요

이 서비스는 시험 일정을 **세 가지 방법**으로 모읍니다.

| 방법 | 어떤 시험 | 누가 |
|---|---|---|
| 공공 API 자동 | 큐넷 국가자격 (정보처리기사·전기기사 등) | 서버가 알아서 |
| 사이트 자동 수집 | 토익·텝스·JLPT | 서버가 알아서 |
| **직접 입력** ← 내 일 | **공무원, 한국사, 국시원(간호사 등), 소방, HSK …** | **매니저** |

> ⚠️ **이 표를 외울 필요는 없습니다.** 운영 화면 맨 위 **데이터 지도**가 지금 기준으로
> 갈래마다 자동인지 수기인지, 어느 사이트를 봐야 하는지까지 보여줍니다(§2-4).
> 스크래퍼가 하나 추가되면 화면 표시도 같이 바뀌니, 화면을 믿으세요.

**왜 직접 넣나요?**
공무원 시험처럼 **1년에 한두 번**만 하는 시험은 자동 수집 프로그램을 만들 값어치가 없습니다.
1년에 두 줄 넣자고 프로그램을 만들고 고장 날 때마다 고치는 것보다, 사람이 넣는 게 훨씬 쌉니다.

그런데 **이런 시험이 제일 중요합니다.** 접수 기간이 3~5일로 짧고, 놓치면 1년을 기다려야 하니까요.
매니저가 넣은 일정이 곧 누군가의 "접수 마감 D-3" 알림이 됩니다.

## 2. 시작하기

### 2-1. 로그인 — 카카오가 아니라 **매니저 전용 주소**입니다

```
http://localhost:8081/manager/login      (배포하면 https://내도메인/manager/login)
```

**아이디와 비밀번호로 들어갑니다.** 일반 이용자가 쓰는 카카오 로그인과는 별개예요.
운영 계정을 카카오에 묶어 두면, 카카오 쪽에 문제가 생기는 날 운영 자체가 멈추고
담당자가 바뀔 때 개인 SNS 계정을 넘겨줘야 하는 이상한 일이 생깁니다.

이 주소는 화면 어디에도 링크가 없습니다. **북마크해 두세요.**

### 2-2. 계정은 누가 만드나요

**가입 화면이 없습니다.** 매니저는 아무나 될 수 없어야 해서, 서버를 만지는 사람만 만들 수 있습니다.

| 어디서 | 어떻게 |
|---|---|
| **로컬(개발용)** | `src/main/resources/data.sql` 이 넣습니다 — **manager / pass1234**. 그냥 됩니다 |
| **운영** | 운영 DB 에 직접 INSERT 합니다 (절차: [02_내가_할일.md](../../진행사항/02_내가_할일.md) 4순위) |

로컬 비밀번호를 바꾸려면 해시를 만들어 `data.sql` 의 값을 갈아 끼웁니다:

```powershell
./gradlew managerHash -Ppassword=새비밀번호
```

평문을 넣으면 로그인이 안 됩니다 — 로그인이 BCrypt 해시와 비교하기 때문입니다.

> 로컬 DB 는 인메모리라 **서버를 끄면 사라지고, 켤 때마다 `data.sql` 이 다시 넣습니다.**
> 그래서 이것저것 눌러 봐도 다음 기동에 원상복구됩니다.

### 2-3. 준비물

- 매니저 계정 (위)
- 시행처 공고 페이지 — **어느 사이트를 봐야 하는지는 화면이 알려줍니다**(2-4)

### 2-4. 들어가면 보이는 것

로그인하면 **운영 화면**(`/admin`)으로 갑니다. 위에서부터 세 덩어리입니다.

**① 데이터 지도 — 뭐가 자동이고 뭐가 수기인가**

지금 몇 종이 들어와 있고 **일정이 없는 시험이 몇 개인지**. 그 아래로 갈래별 목록:

| 표시 | 뜻 | 내가 할 일 |
|---|---|---|
| 🟠 **수기 입력** | 자동 수집이 없다 | **이것만 넣으면 됩니다** |
| 🔵 **자동(대기 중)** | 수집기는 있는데 아직 안 돈다 | 켜지기 전까지는 넣어도 됩니다 |
| 🟢 **자동 수집** | 서버가 가져온다 | **손대지 마세요** — 다음 수집에 덮어써집니다 |
| ⚪ **대상 아님** | 상시·예약제라 마감이 없다 | 넣지 않습니다 |

갈래마다 **시행처 · 어느 메뉴를 봐야 하는지 · 회차 빈도**가 적혀 있고,
**[원본 사이트 열기 ↗]** 로 공고 페이지가 새 탭에서 열립니다.

**② 시험 일정 현황 — 무엇을 채워야 하나** ⭐ 여기가 작업 목록입니다

시험 480종의 상태를 한 표에서 봅니다. 탭으로 나뉘고, **급한 것이 위**로 옵니다.

| 탭 | 뜻 |
|---|---|
| **일정 없음** | 한 번도 안 들어온 시험. **여기부터 채웁니다** |
| **지난 것만** | 등록된 일정이 전부 지나갔다 → 다음 회차를 넣어야 합니다 |
| **접수 중** | 지금 접수 기간(마감 D-day 표시) |
| **예정** | 앞으로 있을 일정이 있음 — 할 일 없음 |

> "지난 것만"을 "일정 없음"만큼 급하게 두는 이유가 있습니다. 끝난 날짜가 **화면에 그대로
> 걸려 있어서**, 사용자는 그게 다음 회차인 줄 압니다. 비어 있는 것보다 오히려 나쁩니다.

시험명으로 좁힐 수 있고, 행 오른쪽 **[넣기]** 를 누르면 아래 입력 폼이 **그 시험으로 바로**
열립니다(다시 검색하지 않아도 됩니다).

**③ 일정 직접 넣기** — 아래 3단계.

> 매니저가 아닌 계정으로 `/admin` 에 들어가면 "매니저만 볼 수 있는 화면입니다"가 뜹니다.

## 3. 일정 넣기 (3단계)

### 1단계 — 시험 고르기

검색창에 시험 이름을 **2글자 이상** 칩니다.

```
예: "국가직"  →  국가직 9급 공개경쟁채용 / 국가직 7급 공개경쟁채용
```

목록에서 원하는 시험을 클릭하면 선택됩니다.

> **시험이 검색에 안 나오면?** 아직 목록에 없는 시험입니다. 개발자에게
> "○○ 시험을 목록에 추가해 주세요"라고 요청하세요(시험 자체를 만드는 건 매니저 화면에 없습니다).

### 2단계 — 이미 등록된 일정 확인

선택하면 그 시험에 **이미 들어가 있는 일정**이 표로 보입니다.
같은 회차가 이미 있는지 먼저 확인하세요. 없으면 새로 넣고, 있는데 날짜가 바뀌었으면 그냥 다시 넣으면 됩니다.

### 3단계 — 일정 입력

| 칸 | 뭘 넣나 | 예시 | 필수? |
|---|---|---|:-:|
| **연도** | 시험 시행 연도 | `2027` | ✅ |
| **회차** | 몇 번째 시험인지 | `1` | ✅ |
| **구분** | 필기/실기. **구분이 없는 시험은 "필기"** | 필기 | ✅ |
| **접수 시작** | 원서접수 시작 날짜 + **시각** | `2027-01-11 09:00` | 권장 |
| **접수 마감** | 원서접수 마감 날짜 + **시각** | `2027-01-14 18:00` | 권장 |
| **시험일** | 시험 보는 날 | `2027-04-10` | 권장 |
| **시험 종료일** | 며칠에 걸쳐 볼 때만 | (보통 비움) | |
| **발표일** | 합격자 발표일 | `2027-05-12` | |
| **출처 URL** | 공고문 주소 | `https://www.gosi.kr/...` | 권장 |

**저장**을 누르면 끝입니다.

## 4. 꼭 지켜 주세요 (중요)

### ① 시각까지 넣어 주세요

접수 마감은 **날짜보다 시각이 중요합니다.** 대부분 "18시 마감"이라 그날 밤에 알림을 보내면 늦습니다.
공고에 "18:00까지"라고 적혀 있으면 그대로 넣어 주세요.

### ② 모르는 값은 비워 두세요

**추측해서 넣지 마세요.** 비워 두면 화면에 "미정"으로 나가고, 값을 넣으면 사용자는 그걸 **확정된 정보로 믿습니다.**
틀린 날짜로 알림이 가면 안 보내느니만 못합니다.

### ③ 출처 URL 을 꼭 넣어 주세요

나중에 "이 날짜 어디서 봤지?"를 확인할 유일한 방법입니다. 사용자 화면에도 출처로 표시됩니다.

### ④ 저장하면 알림 예약이 자동으로 만들어집니다

일정을 넣는 순간 그 시험을 관심 등록한 사람들에게 갈 알림이 예약됩니다.
**날짜를 잘못 넣으면 잘못된 알림이 나갑니다.** 저장 전에 한 번만 더 확인해 주세요.

## 5. 일정이 바뀌었을 때

시행처가 일정을 변경하는 일은 흔합니다.

**그냥 같은 연도·회차·구분으로 다시 넣으세요.** 덮어써집니다.
알림 예약도 새 날짜로 다시 만들어집니다.

## 6. 시험이 취소·연기됐을 때

일정 표에서 그 줄의 **취소**를 누르세요.

- 삭제가 아니라 **상태만 "취소"로 바뀝니다.** 이미 나간 알림의 근거가 사라지면 안 되기 때문입니다.
- 취소된 일정은 사용자 화면에서 사라지고, 예약된 알림도 나가지 않습니다.

## 7. 언제 넣어야 하나요

| 시험 | 공고 시점 | 넣어야 할 때 |
|---|---|---|
| 국가직·지방직 공무원 | 전년도 12~1월 | **공고 나오면 바로** (접수가 1월) |
| 경찰·소방 | 연 2회, 시험 2~3개월 전 | 공고 즉시 |
| 한국사능력검정 | 연 6회, 회차별 1~2개월 전 | 회차별로 |
| JLPT | 3월·9월 | 접수 시작 2주 전까지 |
| 기타 외국어(DELE·괴테 등) | 연 수회 | 확인되는 대로 |

> **접수 시작 전에 넣는 게 핵심입니다.** 접수가 이미 시작된 뒤 넣으면
> "접수 시작" 알림을 보낼 기회가 이미 지나갑니다.

## 8. 자주 있는 상황

**Q. 필기/실기 구분이 없는 시험인데요?**
A. **"필기"** 로 넣으세요. 시스템이 구분을 요구할 뿐, 화면에는 크게 드러나지 않습니다.

**Q. 접수가 1차·2차로 나뉘어 있어요 (추가접수 등)**
A. **본접수만** 넣으세요. 추가접수까지 별도 회차로 넣으면 같은 시험이 두 번 보입니다.

**Q. 시험이 이틀에 걸쳐 있어요**
A. 시험일에 첫날, 시험 종료일에 마지막 날을 넣으세요.

**Q. 발표일이 "1월 말"처럼 애매해요**
A. **비워 두세요.** (§4-② 참고)

**Q. 잘못 저장했어요**
A. 같은 연도·회차·구분으로 올바른 값을 다시 넣으면 덮어써집니다.
   아예 없애야 하면 **취소**를 누르세요.

## 9. 문제가 생기면

| 증상 | 뜻 | 어떻게 |
|---|---|---|
| "운영자 전용 화면입니다" | 권한 없음 | 개발자에게 운영자 권한 요청 |
| "접수 마감이 시험일보다 늦습니다" | 날짜 순서가 어긋남 | 날짜를 다시 확인 |
| "시험을 찾을 수 없습니다" | 목록에 없는 시험 | 개발자에게 시험 추가 요청 |
| 저장은 됐는데 화면에 안 보임 | 취소 상태이거나 다른 회차 | 일정 표에서 확인 |
