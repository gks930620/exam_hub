# 외부 서비스 키 발급 — 큐넷 · 구글 · 메일

> 이 프로젝트가 바깥에서 받아와야 하는 키들. **한 번 받으면 끝이 아니라**
> 배포 환경이 늘거나 키가 만료될 때마다 다시 오게 되는 문서다.
> 카카오(로그인·알림톡)는 절차가 달라 [01_카카오_설정.md](01_카카오_설정.md) 에 따로 있다.

## 0. 무엇이 필요한가

| 무엇 | 어디서 | 왜 | 없으면 |
|---|---|---|---|
| **큐넷 서비스키** | data.go.kr | 국가자격 488종의 실제 일정 | 시험 이름만 있고 일정이 비어 있음 |
| **구글 OAuth** | console.cloud.google.com | 구글 로그인 | 카카오로만 로그인 |
| **JWT 서명 키** | 직접 생성 | 로그인 토큰 위조 방지 | 개발용 기본값으로 뜸(운영은 fail-fast) |
| **SMTP** | Gmail / AWS SES | 카톡을 못 받는 사용자에게 메일 발송 | 로그만 남음 |

## 1. 공공데이터포털 (큐넷) — 커버리지의 70%

### 1-1. 검색어 (그대로 복사)

data.go.kr 상단 검색창 → **오픈API 탭**.

| 순위 | 검색어 | 찾을 것 | 쓰임 |
|:-:|---|---|---|
| 1 | `국가자격 시험일정` | 한국산업인력공단_국가자격 시험일정 조회 서비스 | **접수·시험·발표일** ← 앱의 존재 이유 |
| 2 | `국가자격 종목 목록` | 한국산업인력공단_국가자격 종목 목록 정보 | 488종 이름·계열 |
| 3 | `국가자격 시험정보` | 한국산업인력공단_국가자격 종목별 시험정보 | 응시수수료 |
| 4 | `국가자격 종목별 자격정보` | 국가전문자격 종목별 자격정보 | 시험과목·합격기준 |
| 5 | `국가기술자격 통계` | 국가기술자격 통계정보 | (선택) 합격률 |
| — | `한국산업인력공단` | 위가 안 나오면 기관명으로 전체 보기 | |

> **넷 다 신청해 두는 게 좋다.** 대부분 자동승인이고, 나중에 하나씩 더 신청하면 승인 대기가 또 생긴다.
> 활용 목적은 "개인 학습/토이 프로젝트 — 시험 일정 알림 서비스" 정도면 된다.

### 1-2. 함정 3가지 (실측으로 확인)

1. **키가 두 벌 나온다** — `Encoding` / `Decoding`.
   코드가 URL 을 직접 조립하므로 **Encoding 키**를 써야 한다. 잘못 쓰면 인증 실패만 반복된다.
2. **개발계정은 일 1,000회 제한.** 488종을 매일 다 돌면 넘는다
   → 승인 후 마이페이지에서 **운영계정 전환/증량 신청**.
3. **`openapi.q-net.or.kr` 는 HTTPS 가 안 된다** — HTTP 로만 호출된다(HTTPS 는 타임아웃).
   `apis.data.go.kr` 는 HTTPS 정상. 상세는 [큐넷 API 분석](../시험데이터/큐넷_API/README.md).

### 1-3. 넣는 곳

```
QNET_API_KEY=발급받은_Encoding_키
```
`.env` (프로젝트 루트). 그리고 `qnet.api.enabled=true`.

### 1-4. 키가 생기면 반드시 확인할 것

- **컴퓨터활용능력·워드프로세서가 이 API 에 잡히는가** — 국가기술자격이지만
  시행처가 대한상공회의소라 안 잡힐 가능성이 있다. 안 잡히면 별도 스크래퍼가 필요하다.
- **정보보안기사**도 같다(시행처 KCA).

## 2. 구글 로그인

1. [console.cloud.google.com](https://console.cloud.google.com) → 프로젝트 생성
2. **API 및 서비스 → OAuth 동의 화면** → 외부 → 앱 이름·지원 이메일
3. **사용자 인증 정보 → OAuth 클라이언트 ID** → 유형 **웹 애플리케이션**
4. **승인된 리디렉션 URI**
   ```
   http://localhost:8081/login/oauth2/code/google
   ```
5. **Client ID 와 Client Secret 을 둘 다** `.env` 에 넣는다
   (`GOOGLE_CLIENT_ID` / `GOOGLE_CLIENT_SECRET`) → `oauth.yml` 의 google 블록 주석을 푼다.
   Secret 은 **재발급 직후 화면에서만** 보인다. 나중에 다시 볼 수 없으니 그때 복사해 둔다.

> **Secret 이 없으면 구글 등록이 아예 안 만들어진다.** 그게 정상 동작이고 서버는 그대로 뜬다 —
> 로그인 화면이 `/api/auth/providers` 로 물어서 **구글 버튼을 아예 안 그린다**(카카오만 나온다).
> 단 주소창에 `/oauth2/authorization/google` 을 직접 치면 스프링이 500 을 낸다. 화면에서
> 갈 수 있는 길이 없으니 그대로 두었다 — 키를 넣으면 사라진다.

> 심사 전 단계에서는 동의 화면의 **테스트 사용자**에 본인 계정을 추가해야 로그인이 된다.
> 배포하면 그 도메인의 리디렉션 URI 를 **하나 더** 추가한다(로컬 것은 지우지 말 것).

## 3. JWT 서명 키

32자 이상 아무 랜덤 문자열이면 된다.

```
JWT_SECRET_KEY=32자_이상_랜덤_문자열
```

> 운영에서 개발용 기본값이 그대로면 토큰 위조가 가능하다 — `RailwayDeploymentValidator` 가 막는다.

## 4. 메일 (SMTP) — 카톡 폴백용

알림은 카카오톡이 1순위고, **번호가 없거나 카톡을 못 받는 사용자**에게 메일이 간다.

| 방법 | 준비물 | 특징 |
|---|---|---|
| **Gmail 앱 비밀번호** (시작용) | 2단계 인증 → 앱 비밀번호 | 5분. **일 500통 제한** |
| **AWS SES** | AWS 계정 + 도메인/이메일 인증 | 대량·안정적. 처음엔 샌드박스 |

**Gmail 절차**: 구글 계정 → 보안 → **2단계 인증 ON**(안 켜면 앱 비밀번호 메뉴가 안 보인다)
→ **앱 비밀번호** 생성 → 16자리 복사.

```
MAIL_ENABLED=true
MAIL_HOST=smtp.gmail.com
MAIL_PORT=587
MAIL_USERNAME=본인계정@gmail.com
MAIL_PASSWORD=앱비밀번호16자리
MAIL_FROM=본인계정@gmail.com
```

> `MAIL_ENABLED=false`(기본)면 발송기가 아예 안 뜨고 로그 스텁이 남는다 — SMTP 없이 개발이 돌아간다.

## 5. 알아둘 것 — 키가 없어도 앱은 뜬다

이 프로젝트는 **키가 하나도 없어도 기동**된다. 없는 기능만 조용히 꺼진다.

| 키 | 없을 때 |
|---|---|
| 큐넷 | 데모 10종 + 시드만. 시험 목록·검색은 정상 |
| 소셜(oauth.yml) | 로그인 버튼만 동작 안 함. 조회·커뮤니티 읽기는 정상 |
| 알림톡·SMTP | `LogNotificationSender` 로 로그만 남음 |

**테스트도 키 없이 전부 통과한다** — 인증이 걸린 API 는 테스트에서 JWT 를 직접 발급해 검증한다
(`ApiIntegrationTestSupport.bearer()`). 그래서 키는 "실제 사람이 써 보려면" 필요하고,
개발·검증에는 필요 없다.

> 소셜 로그인 **테스트용 공용 키는 존재하지 않는다** — 카카오·구글 모두 제공하지 않는다.
> OAuth 구조상 Redirect URI 가 앱마다 고정이라, 공용 키를 두면 아무나 그 앱의 사용자 정보를 받아갈 수 있다.
